# API Validator Constitution

Version: 0.1

The API Validator is an application built upon the Kernal Engine.

The API Validator never performs deterministic evaluation.

The API Validator discovers systems.

The API Validator authenticates identities.

The API Validator models resources.

The API Validator executes authorized scenarios.

The API Validator builds Observed Reality.

The Kernal Engine evaluates contracts.

The API Validator interprets Evaluation Results into evidence and findings.

The API Validator never contains domain-independent evaluation logic.

All deterministic evaluation belongs exclusively to the Kernal Engine.
