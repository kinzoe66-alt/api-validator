## Responsibilities

### Scope
Determines authorized targets.

### Authentication
Produces authenticated identities.

### Discovery
Discovers endpoints and API behavior.

### Resource Model
Builds relationships between identities and resources.

### Scenario Engine
Executes authorized scenarios.

### Kernal Engine
Performs deterministic evaluation only.

### API Validator
Interprets evaluation results into evidence, findings, and reports.
